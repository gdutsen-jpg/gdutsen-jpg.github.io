Where are my memories saved?

Memories are stored in this browser’s local database. Keep using the same browser. Clearing browser data, using a private window, switching browsers, or moving the webpage may make saved records unavailable.

Take your photos and stories with you

In Save & backup, choose Save standalone page to create a new HTML file containing all your photos. Open it on another computer to continue your story. Export full backup creates a JSON file you can restore or merge. Export again after adding new memories to keep these files up to date.

Keep your original photos, too

To save space, this book stores still-image copies up to 2400 pixels on the longest side. Back up your originals separately. Publishing an album backup shares the viewing copies. Convert HEIC or other unsupported formats to JPG or PNG before adding them.

A private file on your computer

There is no cloud sync, password lock, or encryption. Anyone who has your backup file or standalone webpage can read its photos and stories. Keep these files somewhere safe.
